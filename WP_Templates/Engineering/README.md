# 공학 산출물 템플릿

이 폴더에는 Tier 프로젝트에서 새 공학 산출물을 작성할 때 사용하는 빈 양식을 보관합니다. `02_Tier/02_WorkProduct/doc/engineering`의 완성된 교육용 샘플은 변경하지 않았습니다.

- DOCX: 기존 공학 문서의 장과 절 구조를 일반화했습니다. 각 제목 아래의 작성 안내를 실제 프로젝트 내용으로 교체합니다.
- XLSX: 기존 시트와 열 구조를 유지했습니다. 10행의 빈 행부터 실제 데이터를 추가합니다.
- DRAWIO: 안내 도형을 삭제하고 실제 요소, 액터, 인터페이스와 추적 ID를 작성합니다. 검토본이나 베이스라인을 만들 때 PNG를 함께 내보냅니다.

템플릿 ID, 적용 산출물과 실제 파일 위치는 상위 폴더의 `PRC-TPL-001_표준 산출물 양식 등록부.xlsx`에 기록합니다. 템플릿을 복사한 뒤 파일명을 `<산출물 ID>_<산출물명>.<확장자>` 형식으로 바꾸고, 프로젝트와 베이스라인 정보를 입력합니다.
